# KiroOS

**An Android system for the Samsung Galaxy S6, S6 edge and S6 edge+**, built on LineageOS 14.1 with its own apps, design and features.

### ⬇️ [Download KiroOS](https://github.com/KiroOS-Project/KiroOS/releases/latest) · 📖 [Install guide](https://github.com/KiroOS-Project/KiroOS#install) · 🛠 [Build it yourself](https://github.com/KiroOS-Project/manifest)

**Latest: KiroOS 1.0 — Developer Beta 5**

| | |
|---|---|
| 🏠 **Kiro Home** | Rewritten: a new app drawer, live widget previews, frosted glass, 3D icons |
| ✨ **kAI** | An assistant in the cloud that speaks with a natural voice |
| 🔊 **Kiro Speaker Engine** | Bass you can feel from the phone's speaker, louder and clean |
| 🔒 **Privacy** | App lock with your fingerprint and an encrypted private vault |
| 🎛 **Control center** | Screen recording, Wi-Fi and Bluetooth tiles, and an editor to arrange it |
| 🎵 **Kiro Sound** | An equalizer for the speaker, headphones and Bluetooth |

### Repositories

- [`KiroOS`](https://github.com/KiroOS-Project/KiroOS): downloads and the install guide
- [`manifest`](https://github.com/KiroOS-Project/manifest): how to get and build the source
- [`kiroos_packages_apps_KiroOS`](https://github.com/KiroOS-Project/kiroos_packages_apps_KiroOS): the KiroOS apps
- `kiroos_*`: the LineageOS projects KiroOS changes (branch `kiroos-5.0`), the Galaxy S6 device trees and kernel

KiroOS is not affiliated with Samsung or LineageOS.
